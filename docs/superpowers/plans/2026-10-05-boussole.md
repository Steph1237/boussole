# Boussole : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mettre en ligne Boussole (spec `docs/superpowers/specs/2026-10-05-boussole-design.md`) : app statique sur GitHub Pages, données privées par utilisateur dans Supabase, fonction nocturne, remplissage par assistant (copier-coller + MCP), migration des données de Stéph.

**Tech Stack:** HTML/CSS/JS vanilla, `@supabase/supabase-js@2` (UMD cdnjs), Supabase (Postgres 17, Auth, Edge Functions, pg_cron, pg_net), `node --test`, GitHub Actions → Pages.

Conventions : projet Supabase `oapcewpqsbbjdlcdeizi` ; URL `https://oapcewpqsbbjdlcdeizi.supabase.co` ; clé publiable `sb_publishable_o5IJJ2Cf6xf6sPCEWHLZag_b9HefoZ_` (publique). Migrations appliquées avec l'outil `apply_migration` et versionnées dans `supabase/migrations/`. Commits fréquents, messages en français.
