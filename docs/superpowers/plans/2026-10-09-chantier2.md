# Chantier 2 : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Spec : `docs/superpowers/specs/2026-10-09-chantier2-plan-sante.md`.

**Goal:** onglet Plan (budget, objectifs, projection), score de santé dans le Pilotage, cours de secours Euronext.
**Architecture:** mêmes couches qu'au chantier 1 : SQL + RLS → stores (démo, Supabase) → calcul pur (`plan.js`) → modules d'interface. Aucun module ne lit la base directement.

## Phase 1 (parallèle, fichiers disjoints)

- **T1 Données** — `supabase/migrations/0004_plan.sql` (tables `budgets`, `objectifs`, RLS, `export_all` étendu), `test/isolation.test.mjs` (2 tables ajoutées), `web/src/store-supabase.js`, `web/src/store-demo.js`, `web/src/demo-data.js` (budget et 3 objectifs d'exemple cohérents avec le foyer Camille/Sam), `test/store-contract.test.mjs`.
- **T2 Moteur** — `web/src/plan.js` + `test/plan.test.mjs` : `budgetTotaux`, `effortMensuel`, `dateAtteinte`, `statutObjectif`, `projection`, `score`, constantes de rendement et repères par âge. Tests écrits d'abord, valeurs vérifiées à la main (annuités).
- **T3 Cours de secours** — `supabase/functions/nightly/index.ts` : repli Euronext, `source` = `yahoo` | `euronext` ; redéploiement ; vérification sur l'instrument existant.

## Phase 2 (après T1 + T2)

- **T4 Onglet Plan** — `web/src/plan-view.{js,html,css}`, enregistrement `App.register("plan")`, ajout à `ORDER`/`LABELS` dans `app.js` et au build ; budget éditable (lignes répétables, pastilles réel pour salaire et mensualités), objectifs (cartes avec jauge, effort, statut, date d'atteinte), projection (courbe 3 scénarios, sélecteur d'horizon), remplissage du budget par assistant (`Assistant.prompt("budget")`, `parse(…,"budget")`).
- **T5 Santé + MCP** — carte de score en tête du Pilotage (`pilotage.{js,html,css}`), outils MCP budget/objectifs + score dans `get_overview` (`supabase/functions/mcp/index.ts`, redéploiement), tests statiques MCP.

## Phase 3

- Vérification visuelle complète (démo, mobile, sombre), `get_advisors`, commit, push, CI verte.
